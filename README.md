# Shiply Backend
# Project Overview

The backend of Shiply provides the data layer for managing deliveries, drivers, and customer interactions. It supports the frontend by exposing structured APIs for logistics operations.

## Key Features
- APIs for managing deliveries and users
- Driver and customer data management
- Delivery status updates and tracking endpoints
- Structured backend logic for logistics operations

## What I Learned
- Designing backend systems for multi-user platforms
- Structuring APIs to support real-time frontend behavior
- Managing relational data between drivers, customers, and deliveries
- Building clean backend logic to support complex frontend interactions
- Understanding how backend data design impacts UI/UX behavior
